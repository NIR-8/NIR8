First-time setup (once)
  1. Firebase console → Authentication → Sign-in method → turn on Email/Password.
  2. Authentication → Users → Add user: email admin@nir8.app, password Caps@1234.
  3. Firestore → Rules: add this block, then Publish.
    match /config/app { allow read: if true; allow write: if request.auth != null && request.auth.token.email == 'admin@nir8.app'; } match /config/history { allow read, write: if request.auth != null && request.auth.token.email == 'admin@nir8.app'; }
  4. Sign in here and change the password straight away.
